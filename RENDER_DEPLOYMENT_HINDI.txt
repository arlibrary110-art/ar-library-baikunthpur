AR LIBRARY MANAGEMENT SYSTEM - RENDER + GOOGLE SHEETS

1. RUNTIME
Render par Runtime = Docker rakhein. Project PHP 8.2 + Apache par chalta hai.

2. DATABASE
Application ka runtime database Railway/MySQL nahi hai. Data Google Sheets me store hota hai aur Google Sheets API ke through access hota hai.

3. RENDER ENVIRONMENT VARIABLES
Ye variables add karein:
- GOOGLE_SHEET_ID
- GOOGLE_SERVICE_ACCOUNT_JSON

GOOGLE_SERVICE_ACCOUNT_JSON ko GitHub me kabhi commit na karein.

4. GOOGLE SHEET
Google Sheet ko service-account ke client_email ke saath Editor ke roop me share karein. Application required tabs aur headers automatically create karti hai.

5. EXISTING RAILWAY DATA
Railway database ko delete karne se pehle existing data migrate/verify karein. One-time migration utility `migration_tools/migrate_railway_to_sheets.php` hai. Ye CLI-only hai aur web se block hai. Migration ke liye temporary `ENABLE_RAILWAY_MIGRATION=1` aur `OLD_DB_*` variables set karke CLI se run karein. Migration verify hone ke baad in sabhi variables ko remove kar dein.

6. IMPORTANT
Google Sheets small/medium workload ke liye suitable hai. High-concurrency production database ke liye MySQL/PostgreSQL jaisa database zyada appropriate hota hai.
