AR LIBRARY MANAGEMENT SYSTEM — LIVE DEPLOYMENT (MONGODB)
==============================================================

1) RUNTIME
Use the included Dockerfile on Render. The application runtime database is MongoDB.
Railway/MySQL and Google Sheets credentials are not required for normal operation.

2) MONGODB ATLAS
- Create a MongoDB Atlas cluster.
- Create a database user with a strong password.
- Allow the Render deployment to connect to the cluster.
- Copy the driver connection string.

3) RENDER ENVIRONMENT
Set:
  MONGODB_URI=<MongoDB Atlas connection string>
  MONGODB_DATABASE=ar_library

Never commit the MongoDB URI/password to GitHub.

4) FIRST ADMIN LOGIN (fresh database)
Staff ID: STF-001
Initial password: AR@Lib#2026!Baikunthpur
Change this password immediately after first login.

5) EXISTING RAILWAY DATA
Do not delete Railway until the new deployment is tested and old data is verified in MongoDB.
The optional CLI migration tool is under migration_tools/. It requires ENABLE_RAILWAY_MIGRATION=1
and OLD_DB_* variables. After migration, remove those variables.

6) TEST CHECKLIST
Test all of the following before retiring Railway:
Admin login, Staff login, Member add/edit, Fees/Payments, Receipt, Attendance, QR attendance,
Seats/Lockers, Enquiry, Expenses, Reports, Backup/Restore, Settings and Member login/profile.

7) SECURITY
Use HTTPS. Keep MONGODB_URI only in Render Environment Variables.
Do not publish private connection strings, SQL dumps, backups or old Railway credentials.
