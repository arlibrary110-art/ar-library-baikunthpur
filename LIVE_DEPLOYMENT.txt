AR LIBRARY MANAGEMENT SYSTEM - LIVE DEPLOYMENT
===============================================

1) HOSTING
Use PHP 8.1+ with MySQL/MariaDB, Apache/cPanel and SSL.

2) UPLOAD
Upload the contents of this folder to public_html/AR_Library_Management_System/.
Keep AR_Library_Private OUTSIDE public_html, for example:
  /home/USERNAME/AR_Library_Private/

3) DATABASE
Create a MySQL database and a separate MySQL user. Give the user the required privileges.
Import AR_Library_Private/database.sql in phpMyAdmin.

4) DATABASE CONNECTION
Edit db.php only if environment variables are not available, and set the hosting database credentials there.
or set AR_LIBRARY_DB_HOST, AR_LIBRARY_DB_USER, AR_LIBRARY_DB_PASSWORD and AR_LIBRARY_DB_NAME as hosting environment variables.
Do NOT use the MySQL root account on the live site.

5) SSL
Enable HTTPS before public use.
The application uses secure session cookies automatically when HTTPS is enabled.

6) FIRST ADMIN LOGIN (fresh database only)
Staff ID: STF-001
Initial Password: AR@Lib#2026!Baikunthpur
Change this password immediately after first login from Admin/Staff Management.
There is no STF-001/1234 recovery backdoor in this release.

7) EXISTING DATABASE
If you already have your library data, DO NOT delete or overwrite your existing database.
Replace the application files first and keep your current database. Take a backup before any schema upgrade.

8) PRIVATE FILES
Never expose database.sql, backups, configuration secrets or uploaded private data through public_html.

9) QR ATTENDANCE
Generate the permanent Attendance QR from the office QR page. The QR does not expire; member login and server-side GPS verification are still required.
The QR URL uses the current HTTPS domain automatically.

10) FINAL TEST
Test: Admin login, Staff login, Member add/edit, Fee/payment, Receipt, Attendance, QR attendance,
Seats/Lockers, Enquiry, Expenses, Reports, Backup and Restore.
